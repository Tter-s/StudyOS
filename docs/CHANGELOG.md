## V3.1.0 界面收敛（财务 / 记录 / 时间分布）— 2026-10-28

**主题**：把「每天怎么用」压到最少点击。

### 财务

- 记录列表改为按天折叠：默认只显示当天支出合计与笔数，点开才展开当天每一笔；搜索或筛选时自动全部展开。
- 右下角新增圆形入口（饼图图标），点开按分类显示当月支出占比环形图，含颜色、百分比与金额。

### 记录

- 移除「每日总结」二级页面与文字输入，记录页顶部直接显示「已完成 X / Y」方框与进度条。
- 睡眠只保留两个时间：放下手机、早上起床。
- 娱乐时间由「小时 + 分钟」两个输入框合并为单个分钟输入框，自动换算为小时与分钟。
- 历史记录保留；点某一天改为进入当天待办（原先进总结页）。

### 课表 → 时间分布

- 底栏「课表」更名为「时间分布」，只呈现今天，按 6:00–12:00、12:00–18:00、18:00–24:00 三段显示，每段列出课程、时间与地点。
- 课程的增删改与原课表全部能力（学期设置、单双周、调课 / 停课、一次性日程、作息、图片导入）收进右上角「课程管理」二级页。

### 其他

- 导航测试同步更新：新增时间分布三段断言，移除每日总结用例；`records_*` 用例改为先滚动再点击。

## V3.1.0 构建体积优化 — 2026-10-28

**目标**：APK 小于 50 MB，不删减功能、不改变 ABI 支持范围。

- `release` 开启 R8 代码压缩（`isMinifyEnabled = true`）与资源收缩（`isShrinkResources = true`）。
- 开启 `jniLibs.useLegacyPackaging = true` 压缩原生库；`arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 四个 ABI 全部保留。
- 保留入口：桌面组件/Worker、PDFBox/FontBox、Room 生成实现；补充 ML Kit 可选依赖的 `-dontwarn`。
- Release APK：**68,949,000 → 29,427,174 字节**（65.8 MiB → 28.0 MiB），下降约 57.3%。
- 验证：`assembleRelease` 成功；`apksigner verify` v2=true、v3=true；`aapt dump badging` 仍为 versionCode 31 / versionName 3.1.0 / minSdk 26 / targetSdk 35，权限保持不变；4 个 ABI、ML Kit 模型（25 个条目）、KaTeX、PDFBox 资源与两个组件资源均在包内。
- 说明：R8 仅影响 release 构建；debug 构建与全部 496 项单元测试不受影响。

## V3.1.0 — 2026-10-26

**主题**：只记录生活，不管理人生。

`versionCode 31` · `versionName 3.1.0` · 数据库 v9 → v10 · 包名 `com.zhixu.studyos`

### 新增

- **每日待办**：按日期记录任务，支持添加、编辑、删除、勾选完成；显示完成数 / 总数、百分比与进度条；未完成不滚入第二天；“明日待办”卡片与独立安排页。
- **每日总结**：每天一条，最多 2000 字；按日期查看/补写；自动显示当天完成数 / 总数并只读列出当天待办。
- **娱乐时间**：按小时 + 分钟手动记录，范围 0–1440 分钟；可跨日期查看、修改、删除。
- **记录中心**：每日总结、睡眠记录、娱乐时间、历史记录四个入口；历史按天汇总待办完成数、总结、睡眠与娱乐。
- **数据库 v10**：新增 `daily_tasks`、`daily_summaries`、`entertainment_records` 三张表；`MIGRATION_9_10` 非破坏性迁移并回填旧任务。
- **旧任务回填**：优先截止日期，否则取最早学习时段日期；保留完成状态、时间、排序与时间戳。
- **备份扩展**：完整备份表清单新增三张表；恢复旧备份时在同一事务内补跑回填。
- **桌面组件**：保留“今日待办”和“下一节课”，均改为读取 V3.1 数据。

### 变更

- 底部导航改为 **今日｜课表｜记录｜财务｜我的**。
- 今日页不再堆叠统计卡片，只保留日期、进度、待办列表与明日入口。
- 记录相关表单全部下沉到二级页面，底部栏自动隐藏。
- 财务首页收敛为一屏：当月收入、支出、结余、最近账目、记一笔；预算、预测、异常分析、分类管理入口移除。
- 课表顶部只保留“添加课程”和“更多”菜单；图片导入、学期设置、一次性日程、作息、调整记录收进菜单。
- 我的页只保留主题、数据备份与导出、版本信息。
- 应用启动不再安排预算、计划、考试、睡前提醒，并取消旧版本遗留的 WorkManager 任务。
- 移除 `INTERNET` 与 `POST_NOTIFICATIONS` 权限；本地 OCR 模型随包。

### 移除（界面与导航）

- AI 学习规划、AI API 配置、统一 AI 服务入口。
- 学习计时、效率分析、科目分类、目标管理。
- 题库、刷题、习题导入、数学助手。
- 自动排程、考试倒计时、长期目标、成就/积分/连续打卡。
- 周报、成长分析、复杂统计。
- 首页卡片排序、数据与同步、彻底删除入口。

> 以上模块的代码与数据表保留为归档层，历史数据不删除，并继续进入完整备份。

### 修复 / 加固

- 恢复流程增加 `.restore_journal` 与数据库哨兵，避免“新文件 + 旧库”或“旧文件 + 新库”。
- 待办、总结、娱乐的输入范围在仓库层再次校验，UI 不是唯一防线。
- 历史记录排除未来日期，避免把计划当成已发生事实。
- 跨午夜或从后台回到前台时，今日页自动刷新日期。

### 验证

- `:app:testDebugUnitTest`：**496 项测试，0 失败、0 跳过**。
- `:app:assembleDebug`、`:app:assembleRelease`：成功。
- Debug APK：78,274,101 字节；Release APK：68,949,000 字节。
- `:app:lintDebug`：0 errors、38 warnings。
- Release 签名：`apksigner verify` v2=true、v3=true。
- 迁移测试覆盖 v1/v2/v6 → v10，断言旧任务回填与新表可写。
- 导航测试覆盖五个底栏、深色主题、课表图片导入、添加待办、明日待办、记录中心四入口、保存总结、财务新增对话框。

### 已知限制

- 未连接真机/模拟器：组件、通知取消、图片导入、真实升级安装与视觉未做物理设备验收。
- 睡眠为手动填写，日期按起床当天；时长需在 1 分钟–16 小时之间。
- 旧任务多个学习时段只取最早一天生成一条待办；旧表仍保留完整时段。
- 恢复会替换全部业务表，恢复前需自行备份。
- CSV 导出仍保留旧模块入口（学习计时、习题），用于导出归档数据。
